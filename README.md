# Sports Intelligence Playbooks

Practical guidance for building multimodal AI workflows for sports—from data
curation and model training to inference, evaluation, and lessons learned.

## Explore the playbooks

**[Open the Sports Intelligence Playbooks →](https://nvidia.github.io/sports-intelligence-playbooks/)**

## About this repository

This repository is the publishing destination for the playbook website. The
complete static site is stored in [`docs/`](docs/) and served with GitHub Pages.

The website is generated automatically and updated through reviewed pull
requests. Files under `docs/` are build artifacts and should not be edited
directly.
